# 三条片子

推荐先做第一条。一个没看过产品的人，能跟着「系统预览不够用 → 按下空格 → 同一个窗口里把项目看完」走完全程。

## 1. 空格键（采用）

- 装置：功能本身当钩子。形式：一个窗口反复换内容，切到下一镜的东西是上一镜里的按键或文件。
- 观众看见的是 Finder 里那个只有蓝文件夹的系统预览，底下有一枚 space 键；键被按下之后，同一份 demo-project 变成 OrangeLen 的文件夹、代码、压缩包和图表。
- 头两秒：右侧已经是系统快速查看里的 demo-project（蓝文件夹、名字、大小），左侧一行字「只有基本信息」，space 键停在窗口下面，键帽上的 space 是橙色。
- 节拍：系统预览 → 按下空格 → OrangeLen 打开整个项目 → 代码 → 包内文件 → 图表 → 371 个后缀 → 结尾标志。
- 样子：浅暖灰桌面 `#E7E3DA`，墨色字 `#1C1C1C`，橙色 `#F25C08` 只给 space、收束标题和 371。西文 Inter，中文文泉驿微米黑。介质是真实的快速查看截图，落在桌面上，带接触阴影。
- 声音：没有音乐来源。按键、一次划过、图表切入、数字落地、标志入画各一声。音乐要另外接。

## 2. 桌面坍缩（更冲的一条，未做）

- 装置：前后对照。形式：多块屏幕先挤在一起，再收成一个窗口。
- 头两秒：桌面上同时摊着系统文件夹信息、一大段纯文本和打不开的模型文件。
- 节拍：摊开的失败预览 → 它们被吸进一个选中的文件夹 → OrangeLen 窗口摊平 → 结尾。
- 样子：同一套橙色，但前半段窗口互相遮挡，后半段只留一个窗口。
- 声音：前半段细碎点击，产品出现时收成一下。

## 3. 文件飞进来（未做）

- 装置：同一个文件跨过几处。形式：文件带着自己的外形飞进下一格。
- 头两秒：一份 `diagram.mermaid` 从屏幕外飞到桌面，文件名可读。
- 节拍：文件落地 → 系统预览只给图标 → 空格 → 图在 OrangeLen 里展开 → 结尾。
- 样子：桌面更空，文件图标是主角。
- 声音：文件落地一声，展开时音乐才进来。
