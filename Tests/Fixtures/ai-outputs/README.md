# AI 产出预览合成示例

所有内容为本仓库合成数据；图片为 64 × 64 橙色方块，参数仅供解析验证，不来自实际图片生成。

| 文件 | 内容 |
| --- | --- |
| `diagram.mmd` | 中文 Mermaid 流程图 |
| `diagram.mermaid` | Mermaid 时序图 |
| `captions.srt` | 两条字幕，含中文、多行和 emoji |
| `captions.vtt` | WEBVTT 文件头、NOTE、voice 标签与 cue settings |
| `sample.mcpb` / `sample.dxt` | ZIP 型 MCP 包，含 manifest、README 和不执行的示例 server/index.js |
| `generation.png` | A1111 参数与 ComfyUI prompt/workflow；tEXt、zTXt、iTXt |
| `generation.webp` | 小端 EXIF ComfyUI UserComment |
| `generation-big-endian.webp` | 大端 EXIF ComfyUI UserComment |

用 OrangeLen 主应用打开文件，或 Finder 空格预览此目录后选择文件。PNG 单文件可能保留系统预览，参数面板使用 OrangeLen 主应用或文件夹入口。字体、颜色和缩放由当前系统/阅读设置决定。
