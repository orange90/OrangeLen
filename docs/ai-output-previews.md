# AI 产出文件预览（2026-10-11）

本轮落实 [格式调研](ai-output-format-research.md) 中用户选定的四类高优先级产出。共享阅读器用于主应用和 Finder 文件夹预览；单文件是否调用 OrangeLen 仍取决于系统 Quick Look 分派。

| 产出 | 预览内容 | 入口与边界 |
| --- | --- | --- |
| `.mmd` / `.mermaid` | 离线 Mermaid 图形、缩放/平移、原始源码切换 | 绘图类扩展；主应用、文件夹和文本归档成员共用渲染器。渲染失败保留源码 |
| `.mcpb` / `.dxt` | 默认显示名称、版本、说明、运行类型、入口及完整 `manifest.json`；目录树按需阅读包内文件 | 归档类扩展；ZIP 结构，与 `.skill` 共用归档预算。清单缺失或损坏仍保留文件树与错误说明 |
| `.srt` / `.vtt` | 开始时间、结束时间、字幕正文表格；筛选、排序、复制、原始源码切换；状态显示有效/无效条数和最后结束时间 | 数据类扩展；保留多行字幕和中文。VTT 的 NOTE/STYLE/REGION 块不作为字幕；标签和样式设置保留在源码，不进行样式渲染或视频同步播放 |
| AI PNG / WebP | 原图可缩放，生成参数以可选中、可复制的文本显示；窄窗上下排列，宽窗左右排列 | 主应用及 Finder 文件夹图片入口。PNG 单文件在本机仍由系统图片预览接管；新增类型声明不保证替代系统 |

## 图片参数范围

- PNG：读取 `tEXt`、`zTXt`、`iTXt` 中的 A1111 `parameters`，以及 ComfyUI `prompt` / `workflow`；支持压缩文本和 UTF-8。参数原文包含提示词、负面提示词、种子、采样器、步数和模型等已保存信息。
- ComfyUI：从节点输入整理文字提示、模型名称、seed、steps、cfg、sampler 等参数概览，同时保留完整 prompt/workflow JSON。这里展示参数与原文，不绘制工作流节点图。
- WebP：有界读取 EXIF ImageDescription / UserComment，识别 ComfyUI `workflow:` / `prompt:` 及已知 JSON 参数字段；支持大小端 TIFF。
- 没有参数的图片维持普通画布。普通备注不自动当作 AI 参数；损坏或超预算参数显示提示，仍可显示解码成功的原图。
- 不推断缺失参数，不验证模型来源或图片是否由 AI 生成；JPEG、XMP、C2PA、外部 sidecar 和归档图片成员的参数面板尚未接入。

## 预算与行为

Mermaid 复用离线 Markdown 图表渲染器：每幅图最多 16 KiB 输入、5 秒渲染等待，有界栅格快照；较大或不合法图表降级原始源码。

字幕最多完整读取 5 MiB、50,000 行、5,000 条有效字幕。普通文件超过 1 MiB 由现有读取器先切换分页源码；只有完整快照才转表格。无效时间码隔离；全部无效时回退源码。字幕允许重叠，显示的结束时间是最大结束时间。

字幕表格按列宽计算换行行高，单元格最多显示五行；完整字幕可通过复制、悬停提示和源码模式读取。

MCP 清单最多 1 MiB，结构解析沿用 JSON 深度/节点上限。包体沿用归档输入/累计展开 64 MiB、5,000 项、单项 5 MiB、压缩比 100、CRC 和路径校验。不安装 MCP 扩展，不执行包内脚本，不解压到磁盘，也不读取清单中引用的外部路径。

图片继续使用 ImageIO：输入最多 25 MiB、原图至 1 亿像素、解码最长边 2048。额外参数最多 32 项、累计 1 MiB；PNG 文本块验证 CRC，压缩文本有界展开；EXIF 最多扫描两个 IFD、每个最多 512 项。切换/关闭取消读取并清除旧面板。

## 示例与验证

合成示例在 [Tests/Fixtures/ai-outputs](../Tests/Fixtures/ai-outputs/README.md)。Finder 选中 `.mmd`、`.mcpb`、`.srt` 按空格可检验单文件入口；选中文件夹按空格，再点 PNG/WebP，可检验参数面板。主应用使用 ⌘O 打开对应图片也可检验。

测试覆盖字幕多行/CRLF/源范围/坏时间码/重叠/上限，MCP 默认概览及包内源码切换，PNG 三种文本块与坏 CRC，WebP 大小端 EXIF，Mermaid 真实离线渲染/源码降级/快速切换，以及图片面板在实际窗口宽窄切换时两块区域均可见。验证记录与截图见 [evidence/ai-outputs](evidence/ai-outputs/README.md)。
