# OrangeLen V1.0

**按下空格预览一切 · Press Space to preview everything.**

以 V1.0 正式版本名称发布，适用于 macOS 14+，通用安装包包含 Apple Silicon 与 Intel 架构。

本次仅调整发行名称、Git 标签与安装包文件名，沿用已有的 Developer ID 签名及 Apple 公证。安装包内容与应用内部版本均保持原样，无需重新签名或公证。

中英文 README 已更新功能介绍和下载入口、更换 Finder 实拍截图，并移除签名开发者姓名与 AI 图片参数宣传。

## 安装

下载 `OrangeLen-V1.0-universal.dmg`，将 `OrangeLen.app` 拖入 `Applications` 后打开。同页提供 `OrangeLen-V1.0-SHA256SUMS.txt` 校验文件。

Finder 未显示 OrangeLen 时，请检查系统设置中的 Quick Look 扩展。Finder 由 macOS 选择文件预览器，部分格式需通过主应用或文件夹入口查看。Intel 实机与其他 macOS 版本尚未完整验收，现有格式子集及资源限制仍适用。

## English

OrangeLen V1.0 is the stable release name for the existing notarized universal installer. Only the release name, Git tag and download filename change. The installer contents and internal application version remain unchanged, preserving the existing Developer ID signature and Apple notarization.

Requires macOS 14+. Download `OrangeLen-V1.0-universal.dmg`, drag `OrangeLen.app` into `Applications`, then open it. SHA-256 checksums are provided alongside the installer.

The bilingual READMEs include revised feature descriptions, a fresh Finder screenshot and updated download links. Existing format and Finder-routing limitations still apply; Intel hardware and other macOS versions have not been fully verified.
