# OrangeLen V1.0.1

本次更新修复部分文件在 Finder 按空格时回退到系统预览的问题，并公开逐后缀的真实调用审计。最低系统为 macOS 14，通用安装包包含 Apple Silicon 与 Intel 架构。

## 修复

- **SQL**：补充 `org.iso.sql` 精确类型，Finder 单文件预览进入 OrangeLen，保留关键词、注释和中文字符串高亮。
- **源码与配置**：补充 `.zsh`、`.bash`、`.r`、`.proto`、`.log`、`.diff`、`.patch` 的精确类型注册。
- **压缩 TAR**：修复 `.txz`、`.tbz2` 的 Finder 预览入口；可浏览归档目录并阅读受支持成员。
- **WFLOW 可选偏好**：仓库提供可恢复的 `scripts/prefer-workflow-preview.sh`。它需要用户主动运行，会同时影响系统 `.shortcut` 动作卡片；正常安装不自动应用。WFLOW 不计作默认安装即可接管的修复。

## 安装

下载本页的 `OrangeLen-1.0.1-universal.dmg`，将 OrangeLen.app 拖入 Applications 替换旧版本，启动一次。必要时到系统设置检查 Quick Look 扩展是否启用。

应用与 DMG 均已使用 Developer ID 签名、通过 Apple 公证（Accepted）、附加票据并通过 staple/validate 和 Gatekeeper 校验。同页提供 SHA-256 校验文件。

## 已验证范围与限制

- 修复前在 macOS 26.6.2 / Apple Silicon 对 371 个后缀逐项 Finder 审计：350 项 OrangeLen、16 项系统正文、5 项系统文件信息，均结合实际界面和调用日志判断归属。
- 随后对剩余 21 项逐项复测，9 项通过新增精确类型进入 OrangeLen，WFLOW 在启用可选偏好后进入 OrangeLen。新公证包的 13 项 Finder 回归确认 SQL 与另外 9 项修复、TXZ/TBZ2 中文成员正文，以及 TS/MTS/DOT 仍由系统处理；回调进程 UUID 与新 Release 二进制一致。
- 本次回归测试 314 项，4 项按环境跳过，零失败；24 个 Mach-O 文件均含 Apple Silicon / Intel 两种架构。内部测试不替代 Finder 接管证明。
- `.ts`、`.mts`、`.dot` 仍受系统分派影响，在本机仅显示基本信息；`.html`、`.htm`、`.xhtml`、`.txt`、`.pdf`、`.csv`、`.svg`、`.text` 仍由系统提供预览。没有声称这 11 项已修好。
- 371 是阅读器后缀清单，不是 371 种语言、完整规范兼容性或全量 Finder 接管率。没有在新构建重新运行全部 371 项。
- Intel 架构完成交叉构建与二进制检查，Intel 实机和其他 macOS 版本尚未完整验收；加密/分卷归档、模型推理及既有格式子集限制保留。

详细证据：[新公证包验收](../evidence/release-1.0.1-2026-10-26/README.md)、[SQL](../evidence/sql-preview-2026-10-26/README.md)、[371 项审计](../evidence/all-formats-2026-10-26/README.md)、[21 项修复](../evidence/provider-fixes-2026-10-26/README.md)、[11 项竞品原生调查](../evidence/competitor-native-2026-10-26/README.md)。

## English

V1.0.1 fixes Finder routing for SQL with syntax highlighting, seven source/config suffixes (`zsh`, `bash`, `r`, `proto`, `log`, `diff`, `patch`), and two compressed-TAR aliases (`txz`, `tbz2`). A reversible WFLOW preference script is available separately; installation does not enable it automatically, and it also affects system `.shortcut` action cards.

macOS 14+, universal Apple Silicon/Intel build. Both the app and DMG are Developer ID signed, Apple notarized with stapled tickets, and Gatekeeper verified. All 24 Mach-O files contain both architectures. SHA-256 checksums are provided. Tests: 314 executed, 4 skipped, zero failures. The notarized build passed 13 Finder checks: ten fixes reached OrangeLen with matching Release binary UUIDs; TS/MTS/DOT retained their documented system-routing limitations.

TS/MTS/DOT still show system metadata on the tested Mac; HTML/HTM/XHTML/TXT/PDF/CSV/SVG/TEXT still use system previews. The 371-suffix reader inventory is not a claim of complete Finder ownership or full specification compatibility. Intel hardware and other macOS versions have not been fully verified. See the linked evidence for exact test scope.
