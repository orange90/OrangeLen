## OrangeLen 0.1.0-preview.3

面向开发者与 AI 创作者的 macOS 预览版。此安装包包含 10 月 15—17 日新增功能，阅读器清单现为 **371 个明确后缀、49 个特殊文件名**；后缀别名分别计数，不代表 371 种完整格式或编程语言。

### 新增功能

- 新增 215 个源码、配置及编译文件后缀，扩展离线语法高亮；二进制 plist 转 XML、Java class 声明/有限字节码、可用 AppleScript 源码读取。
- 新增 **7z、RAR4/RAR5、tar.xz / tar.bz2 / tar.zst**，支持 txz / tbz2 / tzst 别名；可浏览目录并阅读受支持成员，无需安装外部解压工具。
- Arrow IPC / Feather V2 数据样本（含 LZ4/ZSTD）、ONNX 图节点与张量元数据、wheel/VSIX 包信息、JUnit/SARIF/OpenAPI 摘要、离线 Graphviz DOT。
- XMind、FreeMind/Freeplane、OPML、MindManager 导图的受支持子集；保留文件夹与项目目录连续阅读。
- 更新中英文 README、格式清单和三款开源竞品对比。

### 安装与验证

- **macOS 14+，通用二进制包含 Apple Silicon 和 Intel**。
- 使用 Developer ID Application（Zhe Huang）签名，应用与 DMG 均通过 Apple 公证、附有票据并通过 Gatekeeper 校验。
- 打开 DMG，将 OrangeLen.app 拖入 Applications，启动一次；如 Finder 没有使用 OrangeLen，请检查系统设置里的 Quick Look 扩展。
- 同页提供 SHA-256 校验文件。

### 实测与边界

- 最新源码完整回归：313 项，4 项按环境跳过，零失败。
- 新增 215 个后缀逐项 Finder 验收：213 项进入 OrangeLen；`.text` / `.wflow` 由系统接管，OrangeLen 文件夹入口也已验证。
- 新增归档的 7 个 Finder 样例均验证了目录与成员正文，包含 RAR4/RAR5；不代表全部压缩变体都兼容。
- 加密/分卷归档不支持；xz/bz2/zst 仅承诺压缩 TAR，受输入、展开比例、条目数和成员大小预算限制。
- 模型只读元数据，不执行推理；组件、导图、3D、排版均有明确子集边界。
- 编译 Java 不恢复原始源码；run-only AppleScript 不恢复源码；编译 AutoIt 仅显示有限字节。
- Finder 单文件由系统选择预览器，部分类型需从主应用或文件夹入口阅读。Intel 实机及其他 macOS 版本尚未完整验收。
