# OrangeLen V1.1.0 — 应用内升级

**这次手动安装一次，以后就可以在应用内点击升级了。**

V1.1.0 加入「检查更新…」。打开 OrangeLen，在应用菜单中点击它，即可查看新版本与更新说明，确认后下载安装并重新启动，不用再手动下载 DMG、拖动替换。

## 升级提示

- **从 V1.0.2 或更早版本升级到 V1.1.0：**请下载本页的 `OrangeLen-1.1.0-universal.dmg`，将 OrangeLen.app 拖入 Applications 替换旧版，然后先启动一次。
- **从 V1.1.0 升级到以后发布的版本：**打开 OrangeLen →「检查更新…」→ 安装更新 → 安装并重新启动。
- 安装包仍来自本项目的 GitHub Releases。当前仅在主动点击时检查，不启用后台自动安装。
- 更新前关闭正在查看的 Quick Look 窗口，重启应用后再回到 Finder 按空格预览。必要时在系统设置中检查扩展是否启用。

## 本版改动

- 接入 Sparkle 2.9.6，提供更新说明、下载进度、安装和重新启动界面。
- 更新清单与安装包均使用 Ed25519 签名验证；安装包在解压前校验。
- App 与内嵌的七个 Quick Look 扩展随完整应用一起升级。
- 发布流程增加 `appcast.xml` 生成、签名与验证，复用 GitHub Release 安装包。
- 中英文安装说明明确提醒：安装或更新后先启动一次 App。

## 系统与验证范围

macOS 14 及以上，版本 1.1.0 / build 6，通用安装包包含 Apple Silicon 与 Intel 架构。

开发阶段已在独立测试 App 上跑通发现更新、下载、安装、重新启动，并核对更新后的版本与签名。315 项 Swift 测试中 4 项条件跳过、0 失败；16 项 Python 检查通过。

Intel 实机、其他 macOS 版本和全量格式尚未完整验收；现有 TS/MTS/DOT 的系统分派限制保留。类型声明检查不代表 Finder 必定使用 OrangeLen。首次支持应用内升级的是本版，旧版不会自动获得该入口。

## English

**Install V1.1.0 manually once. Future versions can be installed from inside OrangeLen.**

Open OrangeLen and choose **Check for Updates…** from the app menu. Review the release notes, download the update, then choose **Install and Relaunch**. Downloads continue to come from this project's GitHub Releases.

V1.0.2 and earlier do not include the updater. To get V1.1.0, download `OrangeLen-1.1.0-universal.dmg`, replace the app in Applications, and launch it once. Close any open Quick Look previews before updating and reopen them afterwards.

This release uses Sparkle 2.9.6, verifies signed update feeds and archives, and updates the app and its seven embedded Quick Look extensions together. Checks are manual; automatic background installation is disabled.

macOS 14+, version 1.1.0 / build 6, universal Apple Silicon + Intel binary. Intel hardware and other macOS versions have not been fully verified. Existing preview-format and Finder-routing limitations remain.
