# OrangeLen V1.0.2

修复 V1.0.1 中被开发机环境掩盖的文件类型登记缺口。此前，本机安装的 Xcode 提供了部分类型声明；在没有这些声明的机器上，Finder 可能无法将文件交给 OrangeLen。

## 修复

- **SQL（Issue #2）**：主应用自行登记 `.sql` 后缀，复用现有语法高亮；保留 `org.iso.sql` 兼容声明。
- **INI / CONFIG / TOML**：主应用补入对应类型及后缀声明，不再依赖 Xcode 提供登记。
- **Markdown**：补入 `.md` / `.markdown` 类型声明，减少对 Notes 或其他编辑器登记的依赖。
- **发布检查**：新增仅使用应用包与系统 CoreTypes 的 371 后缀审计，检查类型登记、父类型和预览扩展候选；纳入测试、CI 及签名前检查。

## 安装

下载本页的 `OrangeLen-1.0.2-universal.dmg`，将 OrangeLen.app 拖入 Applications 替换旧版本，启动一次。必要时到系统设置检查 Quick Look 扩展是否启用。

最低系统 macOS 14，内部版本 1.0.2 / build 5。通用安装包包含 Apple Silicon 与 Intel 架构。

应用与 DMG 均已使用 Developer ID 签名，通过 Apple 公证（Accepted）、附加票据及 Gatekeeper 校验。同页提供 SHA-256 文件。

## 已验证内容

- 完整回归：315 项 Swift 测试，4 项按环境跳过，零失败；另有 10 项 Python 注册与资源测试通过。
- 应用及 7 个扩展均为 1.0.2 / build 5；全部 24 个 Mach-O 文件包含 arm64 与 x86_64。
- 实际发布应用的 371 后缀声明审计：339 项由应用登记，32 项由当前系统 CoreTypes 提供；登记缺口、缺少父类型、缺少预览候选均为 0。

## 验证边界

371 是支持后缀清单，声明链检查通过不代表 371 项 Finder 实测通过。干净 macOS 27、Intel 实机和其他系统版本尚未完整验收；TS/MTS/DOT 的系统分派限制及既有格式子集限制保留。

## English

V1.0.2 fixes file-type registration gaps that were masked by Xcode on the development Mac. OrangeLen now supplies its own `.sql` registration and imports the INI, TOML/CONFIG and Markdown declarations it needs, while retaining compatibility with existing type identifiers.

A new check audits all 371 listed suffixes using only the product's declarations and the current OS CoreTypes, including parent types and preview-extension candidates. It runs in tests, CI and before release signing. Declaration coverage is not a claim of complete Finder ownership.

macOS 14+, version 1.0.2 / build 5. Clean macOS 27 and Intel hardware have not been fully verified. Existing TS/MTS/DOT routing limitations remain.

Tests: 315 Swift tests executed, 4 skipped, zero failures; 10 Python checks passed. All 24 Mach-O files include arm64 and x86_64. The packaged app passed the 371-suffix registration audit against macOS 26.6.2 CoreTypes.

Both the app and DMG are Developer ID signed, Apple notarized, stapled and Gatekeeper verified.
