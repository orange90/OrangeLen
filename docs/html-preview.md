# HTML 效果预览与代码外观

2026-10-10：HTML 在 OrangeLen 阅读器中默认显示页面效果，可用顶部「效果 / 源码」切换；HTML、HTM、XHTML 后缀大小写不敏感。适用于宿主打开文件、文件夹内文件及归档内 HTML。不修改 Finder 单文件 UTType 分派；系统接管的 HTML 仍由系统预览。

## JavaScript 与资源加载

按用户本次要求，HTML 已从静态受限渲染改为启用 JavaScript 和外部资源的 WebKit 页面。普通文件直接使用真实 file URL 加载，不再注入阻止资源的 CSP；页面自己的 CSP、WebKit CORS、证书验证和 file URL 规则仍然生效。支持内联/外置脚本、HTTP/HTTPS 样式表、图片、字体、模块脚本及 fetch（仍受浏览器跨域规则约束）。Web 内容允许普通 HTTP，其他原生下载服务的规则不变。

打开文件夹后，在其中选 HTML，可使用该文件夹的已有读取权限加载相对路径 CSS、JS、图片。单独打开 HTML 时，macOS 授予一个文件不等于授予同目录资源；顶部「允许本地资源…」可选择文档所在目录，使用现有临时目录授权机制。宿主保持文档打开时可将授权共享给 Finder；关闭文档后结束。也可以从文件夹预览进入，无需单独授权每个资源。

归档中的 HTML 保留内存文本入口，可执行内联脚本及加载绝对网络 URL；尚未提供归档成员之间的资源 URL 服务，因此归档内相对路径资源不等同解压后的页面。Markdown 内原始 HTML 仍作为文本，本次改变只适用于 HTML 页面预览。

WebKit 使用非持久会话，不共享用户浏览器已有的登录状态、扩展或 Cookie。页面不具备原生文件/命令消息桥。源码仍保留原文供复制。顶层跨页面跳转、弹窗和下载不是预览功能；需要完整页面交互可使用「在浏览器打开」，交给默认浏览器打开当前原文件。原文件入口只适用于真实文件。

## Finder 显示

Finder 扩展中嵌入 WebKit 的远程图层在本机显示为空白，因此使用原生可滚动页面快照。脚本和网络加载照常在 WebKit 中执行，页面完成加载后生成快照。隔离脚本环境中的 MutationObserver 记录 DOM 与图片加载变化，Finder 每秒至多检查一次，有变化且没有快照正在生成时才更新；源码模式不生成后台快照。窗口宽度或主题改变时重新生成。

Finder 的快照不提供按钮交互、连续视频/Canvas 动画或浏览器级帧率；宿主直接 WebKit 页面支持页面内按钮交互。主应用的「在浏览器打开」提供完整浏览器入口；实测 Quick Look 扩展启动默认浏览器被系统拒绝，因此 Finder 不显示此入口。

只对完整且不超过 1 MiB 的 HTML 创建页面，大文件继续分页源码。初次加载/快照 30 秒未完成、加载失败或 WebKit 内容进程终止时回退源码。Finder 快照最多 8000 点高度、800 万像素，超长页面提示并保留完整源码。页面缩放使用现有 A− / A+；查找命中后切回源码。切换文件、取消与关闭时清理 WebKit、定时检查及临时读取权限。
