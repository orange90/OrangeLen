# 当前入口与边界契约（2026-10-08）

此文件记录当前实现；测试、签名和现场观察的结果以 [修复验收状态](boundary-fix-status.md) 为准。[历史审查](boundary-review-2026-10-08.md) 与各日期截图保留作追溯，不代表缺陷仍存在或最新版已现场通过。系统优先分派和 Finder 键盘限制仍按既有用户取舍处理。

## 格式 × 入口

| 格式 | Finder 单文件 | Finder 文件夹内 | 宿主 | 归档成员 |
| --- | --- | --- | --- | --- |
| 代码、Markdown、JSON/JSONC/JSON5、CSV/TSV、普通文本 | OrangeLen 声明匹配时；系统可优先分派 | 原生正文/树/表格，超 1 MiB 为分页源码 | 同左 | 有界文本/Markdown；不递归开启任意容器 |
| Notebook、HAR、JSONL、diff、普通 gzip | 对应类别声明匹配时 | 内容预览；Notebook 连续正文 | 同左 | 文本成员按源码/Markdown 显示 |
| ZIP/TAR/TGZ、EPUB、SQLite | 对应类别声明匹配时 | 归档目录、书籍章节、SQLite 表格 | 同左 | 不执行嵌套容器/数据库 |
| Excalidraw、SVG | 对应类别声明匹配时 | 离线图像及源码降级 | 同左 | SVG 为源码；不运行脚本 |
| 栅格图片 | 保留系统处理 | ImageIO 有界解码 | 同左 | 有界栅格图片 |
| PDF | 保留系统处理 | PDFKit，只读 | 同左 | 不开启 PDF 解析器 |
| DOC/DOCX/DOCM/DOT/DOTX、RTF、ODT | 保留系统处理 | 无网络 XPC 导入后显示文字/基本字体 | 同左 | 不调用系统导入器 |
| XLSX/XLSM/PPTX/PPTM | 保留系统处理 | 内部 XML 的内容预览 | 同左 | 不开启 Office 内容解析器 |
| MP4/MOV/M4V、M4A/MP3/WAV/AIFF 等 AVFoundation 媒体 | 保留系统处理 | 经校验 FD 流式播放，默认暂停 | 同左 | 不开启播放器 |
| 旧 XLS/PPT、iWork、RTFD、3D 等系统格式 | 系统预览 | 明确提示 Finder 单文件预览 | 系统 Quick Look 交接；可能只显示图标 | 不支持正文 |
| 普通目录（包括 .png/.mp4 名字） | 文件夹类别启用时 | 目录树 | 目录树 | 归档目录节点 |
| 真实文件包 | 系统优先 | 不递归进入；按格式交接或提示 | 按格式交接 | 不视为本地 package |

“对应类别”不保证 LaunchServices 最终选择 OrangeLen。任何不支持/损坏/超限内容都不能显示为前一文件的成功内容。未知格式提供默认应用和 Finder 出口。

## 状态、恢复与保真

- 新请求立即显示当前文件/条目的加载态。成功/部分/空/失败/取消都保留可见状态；失败正文不保留旧文档；数据库失败后清空并禁用表格、复制及旧页操作。
- 父容器保留更多操作，能取消整个子任务树、重载、默认应用打开和返回目录。取消时若保留普通文本，状态明确写明“取消前快照”。关闭释放正文、模型、图片、播放器、scope 和待执行任务。
- 分页搜索、复制、行号限当前页；可回到开头。保留最近 128 个向前历史位置，超出后仍能回首页。关闭先保存，截断或编码变化自动回首页并说明原因。只有文件开头的 BOM 是编码标记，页首内容 U+FEFF 保留。
- JSON 原始值/数字词面/重复键按源码范围读取，路径采用共享祖先表示；Notebook/HAR/Office 的合成内容不是原文件字节副本。CSV/TSV 行复制对含制表符、换行和双引号的字段使用双引号包裹、内部双引号加倍。
- SQLite 显示/辅助功能保留 NULL、数值、TEXT、BLOB、非 UTF-8 TEXT 类型。复制菜单明确使用 SQL 字面量：NULL、`'NULL'`、`X'00FF'` 不混淆；内含 NUL 或无效 UTF-8 的 TEXT 用 `CAST(X'…' AS TEXT)` 保真。行复制是这些字面量组成的转义 TSV，不执行 SQL。
- Office 内容预览按内部部件顺序，可能包含隐藏部件；单元格地址与原始序列数不等于 Excel 显示格式。只读已保存的公式缓存，不计算、更新或执行宏。原生文档导入只保留文字和基本字体，省略活动链接及附件，附件位置为 □；不承诺完整 Word 排版。
- 目录树续页带修订校验；增删/改名导致变化时停止混合列表，提供重新读取。已加载项目统一目录优先/自然排序并去重，筛选仍只针对已加载项。递归统计独立停止/重启，包含隐藏项及包内容的元数据、不跟随链接，持续到完成；跳过权限/云目录则显示部分。扫描期间发生变化不构成事务快照，可重新统计。
- 设置通过 CFPrefs 的独立字段键合并本视图修改；可写存储另有稳定文件锁与原子快照。Quick Look 拒绝共享文件系统写入时仍能修改设置，阅读记录回退到可用的进程容器。清除阅读记录发布跨进程清除代次，同时使所有当前阅读会话失效，重新打开才可保存新记录。隔离容器中的旧记录不再读取，并在该容器下次读写时清理。记录最多 200 项/30 天；不写正文。
- 本地图片授权限定文档、修订与目录。共享 lease 30 秒，5 秒续约；关闭撤销。墙钟回退、跨启动、包含休眠的连续时钟过期均失效。重复授权立即发布新 owner，旧 owner 不能撤销新授权。无 app group 时不宣称跨进程共享。
- 加载完成和错误状态发出辅助功能公告，正文和表格保留可读身份/类型。窄窗折叠后从更多操作访问恢复功能；完整 VoiceOver 听读、高对比和多显示器仍需对应现场验收。

## 预算与隔离

| 路径 | 当前策略 |
| --- | --- |
| 完整文本/结构 | 完整读取上限 5 MiB；普通入口超过 1 MiB 按 64 KiB 分页；64 层、20,000 节点；JSON 单路径 64 KiB、估算模型 16 MiB |
| 高亮 | 后台独立单 worker；主线程只绘制 tokens；每份全文 250,000 UTF-16 / 分页 16,384；缓存 12 项且总估算 8 MiB；过载允许保持无着色正文 |
| 解析队列 | 每进程最多 2 个执行 + 2 个等待；取消立刻释放等待闭包。开始前 RSS ≥512 MiB 时拒绝新任务，提示关闭其他预览再重载；这是准入水位，不是操作系统硬内存限额 |
| 跨进程 | 有签名且可写的 app group 时内核 flock lease 最多 4 个解析、2 个高亮、1 个目录统计；进程退出自动回收。无共享 group 或 Quick Look 额外沙盒拒绝共享锁时仅应用进程内上限，不能承诺全机器总 RSS |
| 目录统计 | 独立单 worker，深度优先枚举；每 256 项让出约 2ms；约 0.2s 进度且主线程至多排队一次最新进度；不再用总项数/总秒数截断 |
| 目录树 | 每批 500；每轮扫描 20,000 项/3 秒；与完整统计的预算不同 |
| 归档 | 输入/累计展开 64 MiB，5,000 项，单项 5 MiB，压缩比 100；不落盘解压；拒绝路径别名/冲突，读取校验实际长度和 CRC |
| Office | 输入 25 MiB；ZIP 全部条目预检、实际展开/CRC 校验；内容正文累计 5 MiB，追加前收费，共享字符串池另有同等预算 |
| 原生文档 | 独立 App Sandbox XPC，无网络或用户文件权限；只接收字节和白名单类型。单服务只接收一个在途请求，5s watchdog / 256 MiB RSS 观察水位触发进程退出；客户端先等待最多 30s 服务冷启动握手，再给导入 6s；超时/取消使连接失效并终止正在导入的服务。返回有界 JSON 文字/字体片段，不传系统附件对象 |
| 媒体 | 逐段 O_NOFOLLOW 打开、拒绝 dataless/特殊文件；FD 保持身份，每个 64 KiB 读取前后检查大小、mtime、ctime、路径 inode。64 GiB 文件上限，单会话累计读取 4 GiB、最多 8 个请求、每请求 10s；AVAsset forbidAll 禁止外部媒体引用；可重载或默认应用打开 |

系统 provider 的同步协调、底层 I/O、cmark/词法 JS 调用仍不能在任意指令点抢占；取消后不提交旧结果，队列及内存准入防止无限叠加。原生系统导入是可终止进程。真实第三方云盘、撤盘、所有编解码器及恶意同元数据篡改不是本机测试可以证明的全覆盖保证。
