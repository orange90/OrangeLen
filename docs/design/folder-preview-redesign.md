# 文件夹预览设计提案

2026-10-08，来源：用户否定当前纯文本统计布局，要求先出设计图。用户随后明确认可设计并要求实现。当前已实现原生 AppKit 版本；原设计图中内容分类及 README 摘要为示意，应用中读取实际文件展示。

## 信息与布局

- 标题栏保留系统关闭、全屏、分享。工具栏只保留侧栏切换、概览、刷新和更多。阅读/源码、正文查找与复制在选择文件后出现。
- 左侧 220–240 pt：文件名筛选、可返回的“文件夹概览”、文件树；隐藏/忽略项开关置底。文件名用正常正文颜色，避免看似禁用。
- 右侧边距 28–36 pt：文件夹图标 + 名称（仅一次）+ 路径。
- 关键数字横排：逻辑总大小、递归项目总数、文件/文件夹数。标签在上，数字在下。符号链接非零时显示额外信息，不跟随目标。
- 内容分类按文件数显示分段条与文字图例；以实际扩展名分类，未知类型归其他。文件夹不参与文件类型图；分类合计应等于文件数。
- README 存在时显示短摘要与打开入口；不存在时隐藏，不生成虚构介绍。预览长度受限。
- 文件夹信息显示位置、统计范围；创建/修改时间如可用可增加，修改时间不能标成全目录最新修改。
- 底部只保留一行统计口径，移除重复总量与大段解释。技术说明收进信息按钮。

## 字体与颜色（浅色基准）

使用系统字体 SF Pro / 苹方；实现时用系统语义色适配深色模式。

| 内容 | 字号 pt | 字重 | 颜色 |
| --- | --- | --- | --- |
| 文件夹名称 | 24–26 | semibold | label / #1D1D1F |
| 核心数字 | 26–28 | semibold、等宽数字 | label / #1D1D1F |
| 区块标题 | 14–15 | semibold | label |
| 文件名、README 正文、信息值 | 13–14 | regular | label |
| 路径、指标标签、完成状态、辅助提示 | 11–12 | regular | secondaryLabel / #6E6E73 |
| 可点击文字 | 12–13 | regular 或 medium | link / #007AFF |
| 部分结果/权限问题 | 12 | regular | 系统橙色 + 文字状态，不仅靠颜色 |

主背景 #FFFFFF；侧栏/指标底色 #F5F5F7；分隔线 #E5E5EA。圆角 8–10 pt，不使用厚阴影。

## 状态和适配

- 统计中显示“已统计大小”“已发现项目”，数字持续更新；完成后切换为总量。
- 停止/权限问题保留已得到数字并明确状态；重新统计/停止放在状态附近，避免两个大按钮长期占侧栏。
- 切换文件不显示概览大指标；点击左侧“文件夹概览”返回。概览进度不能覆盖文件正文。
- 宽度不足时内容区可垂直滚动，指标允许两列或纵向排列；无横向挤压。
- 色条仅辅助，始终保留文字数量；深色、高对比模式用系统语义色。

## 实现与验证（2026-10-08）

- `FolderOverviewView` 原生滚动概览，类别由 `FolderSummary` 同一遍递归扫描统计；符号链接不参与文件分类。README 先读取最多 32 KiB 的完整字符页，解析为纯文本，不加载任何图片；显示标题及最多三行/240 字正文摘录，可打开全文。
- 没有 README 隐藏该区；读取失败保留明确提示。项目声明的旧长说明不再堆在概览中。
- 125 项 SwiftPM 测试登记，123 通过、2 原生 XPC 宿主用例跳过，0 失败；后续外观微调的 12 项相关回归另行通过。新增分类总和/隐藏项/链接/多字节长 README/文件与概览切换/窄窗布局检查。
- 本机开发构建/安装、真实 Finder 浅色概览、README 打开与返回已核验。安装期间旧扩展失效一次，关闭旧预览后重新打开正常；未发现对应的崩溃报告。

- 最终本机安装后，宿主真实浅色/深色截图见 `docs/evidence/folder-redesign/overview-{light,dark}.png`；README 打开与返回再次通过，恢复跟随系统。Finder 中另观察到大目录 37,081 项时仍显示实时扫描状态；此为进度现场证据，不代表完成扫描或压力测试。
