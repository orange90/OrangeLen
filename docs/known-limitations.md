# 当前限制（2026-10-08）

当前实现与入口矩阵以 [当前契约](current-contract.md) 为准，实际通过的验证见 [修复状态](boundary-fix-status.md)。旧“全部文件 5 MiB”“43 项测试”“目录统计达到 20,000 项退出”和阅读尺等描述已过期。

- Finder 键盘转发、系统类型优先分派是用户已接受的取舍；不安装全局监听或抢占泛用 UTI。未支持的 RAR/7z/MOBI 等仍是范围外功能。
- 超 1 MiB 文本为 64 KiB 按钮分页，搜索/复制限当前页；没有跨页词法状态和连续滚动。结构、图像及容器受明确预算约束。
- 文档导入保留文字/基本字体，附件与复杂排版降级。Office 内容值不代表已重新计算或按单元格格式显示。系统 Quick Look 交接可能仅显示图标。
- 原生导入可用独立进程终止；provider 同步协调、内核 I/O、cmark 和词法 JS 不保证任意时刻强行中断。RSS 水位是准入与轮询保护，不是严格的全机器内存硬上限。没有共享 app group 或 Quick Look 拒绝共享目录写入时只有进程内并发限制。共享文件系统不可写时，设置仍通过独立 CFPrefs 字段共享，阅读记录使用可用的进程容器；不承诺这时宿主与 Finder 之间恢复同一记录。
- 目录总计持续直到完成或用户停止，统计元数据逻辑大小，不等于磁盘实际占用；扫描过程不是文件系统事务，变化后可重新统计。
- 自动测试可覆盖修订、取消、墙钟回退、连续时钟过期及清除记录。真实第三方云盘休眠/下载、拔盘、全部辅助功能听读、高对比和多显示器还需要对应实机，不能把代码检查当现场通过。
- 本机 Apple Development 与正式 Developer ID 分发不同。公证、staple、Gatekeeper、其他 macOS 和 Intel 实机必须由相应环境补验；通用二进制构建不代表这些运行验收。
