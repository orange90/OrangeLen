# 已知限制与剩余工作

此版为可构建运行的 M1 开发交付，M0 已满足原生能力验证退出条件；M1 尚未完整验收。

1. **Finder 文件夹验证已推进。** 用户实测确认可以点击文件进入预览；本次修复了按钮不保留选中态，Finder Makefile 同窗正文、选中背景、目录总计已观察通过。PNG 共享渲染器在安装后的宿主及测试中通过；自动化 Finder PNG 点击仍不稳定，未把宿主截图算作 Finder 图片验收。任意目录/完整键盘交互仍待继续验证。
2. **Finder 键盘搜索：已知限制，用户接受，不阻塞验收。** 查找按钮请求 first responder 后，模拟键入仍流向 Finder 选择其他文件；⌘F 也可能打开 Finder 自己的搜索。AX 设置查询文字及结果按钮可验证搜索算法，但不算正常输入体验通过。全选+复制按钮已比对原文通过；任意鼠标拖选、⌘C 和 Option 导航需最终版手动/其他输入路径复核。不安装全局键盘监听，不使用私有 API。
3. **系统格式优先：用户接受，不要求抢占。** CSV 可沿用系统预览；`.ts` 实际系统类型是视频；QLMarkdown 用户报告已卸载，历史竞争不再列为当前问题。早期文件夹被系统接管，最终安装后成功，说明注册/缓存/进程状态影响大；未确定单一原因。不能宣称跨机器可靠。
4. Markdown 已补齐原生表格、嵌套/有序列表、引用/代码块和授权本地图片。单独预览 Markdown 时 Finder 未必授予邻接图片读取权限，本机该情形显示占位；宿主授权目录入口的本地图片通过。远程图片经用户点击加载，Finder 经内嵌 XPC 图片服务已通过公共图片实测；仅公共 HTTPS 栅格，拒绝重定向和私网。链接已实现文内标题、受限本地路径及显式点击 HTTP(S)；外部链接真实点击未验证。公式与 Mermaid 已实现并在 Finder 实测；支持范围/预算见 markdown-rich-content.md，非完整 TeX，图像内字形不能逐字选取。Obsidian 扩展语法及完整 HTML 渲染未实现。少量无法精确展开的 AST 转换采用整节点源映射并告警。复制渲染文本保留 Markdown 原文语法。
5. 高亮是有界词法规则；YAML/TOML/XML 无语义树。目录仅展开项过滤，无全项目内容搜索；项目摘要为基础说明，无 manifest 解析；包/符号链接不进入。
6. 文件限 5 MiB，高亮限前 250,000 UTF-16；结构/阅读分块导航限 20,000 节点，极长文件正文仍可读但不能宣称全部焦点导航覆盖。CSV 只解析前 5,000 行，源码模式可查看界限内完整文件。
7. 协调读取或 cmark C 函数执行中无法强行打断；完成结果仍检查取消。真实云提供商的无下载行为、极端目录、并发首启盐值、崩溃恢复、VoiceOver/高对比/多屏仍待测。
8. 已有 Apple Development 身份构建可在本机运行；Developer ID、分发公证、staple、Gatekeeper 发布验收未执行。macOS 14/15、其他 26 版本、Intel 未测试。

可用替代：宿主 ⌘O 打开文件夹/文件可继续阅读；这是明确标注的补充入口。按 verification.md 顶部最新验收口径推进；键盘搜索和系统接管不再作为阻塞。

新增图片限制：输入 25 MiB，源像素 1 亿，最长边 2048 解码；动图首帧。不代表 PDF/视频/任意系统可预览格式均已支持。目录总计为有预算的元数据快照、逻辑文件大小，不是磁盘占用；达到预算会标部分。
